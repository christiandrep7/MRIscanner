🧠 MRIscanner

Brain tumor classification (glioma / meningioma / pituitary / no tumor). All inference runs on a dedicated EC2 backend -- this page is just the UI. Not a diagnostic tool.

Click or drop an MRI scan here

Runs the selected model(s) against the full held-out test set (1600 scans none of them were trained on or used for checkpoint selection). Can take a few minutes.

Three architectures compared: ResNet50 (95.0% held-out accuracy), VGG16 (94.2%), EfficientNet-B0 (92.7%).
Source: github.com/christiandrep7/MRIscanner
